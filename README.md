# Forest Fire and Smoke Image Classification

Classify images into fire, smoke and non-fire categories.

## Technical approach

Explore convolutional networks, EfficientNetB0 and MobileNetV2 transfer learning, image augmentation and classification evaluation.

## Technologies

TensorFlow, Keras, scikit-learn, NumPy

## Project materials

- `riepl final notebook.ipynb`
- `Riepl final presentation.pptx`

## Getting started

Obtain the forest-fire-smoke-and-non-fire-image dataset referenced in the notebook; adjust local/Kaggle paths. Not a validated emergency detection system.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
